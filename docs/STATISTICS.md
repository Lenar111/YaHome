# Статистика и история

Яндекс не хранит историю показаний датчиков и не отдаёт её через API, поэтому виджет **копит историю сам**.

## Что записывается
Для каждого датчика (и устройства, у которого есть такое свойство): `temperature`, `humidity`, `co2_level`, `pressure`, `power`.
Запись — раз в ~5 минут, пока виджет запущен. Ключ ряда: `"<deviceId>|<instance>"`.

## Формат файла
`~/Library/Application Support/YaHome/history.json`:
```json
{ "<deviceId>|temperature": [[1730180000.0, 23.6], [1730180300.0, 23.7]] }
```
Пары `[unix-время, значение]`, отсортированы по времени.

## Хранится без ограничения по сроку — и не разрастается
Чтобы можно было открыть любой день из прошлого и при этом файл не рос неограниченно, старые данные усредняются
(`HomeModel.compactSeries`, вызывается при загрузке и раз в сутки):

| Возраст точки | Детализация |
|---|---|
| до 14 дней | как записано (≈5 минут) |
| 14 дней – 2 года | среднее за 30 минут |
| старше 2 лет | среднее за 1 час |

Порядок величины: год ≈ 17 500 точек на показатель в 30-минутной детализации.

## Окно просмотра
Состояние: `statsPeriod` (сутки / неделя / месяц / год / свой период), `statsAnchor` (`nil` — «сейчас», иначе выбранная дата),
`customFrom`/`customTo`. `statsWindow()` возвращает `(от, до, живое?)`:
- «живое» — скользящее окно до текущего момента;
- с якорем — календарно выровненные границы (сутки, 7 дней, месяц, год);
- свой период — от начала первого дня до конца последнего.
Стрелки сдвигают якорь на сутки/неделю/месяц/год; запретить уход раньше первой записи помогает `historyStart`.

## Построение графика
- Точки усредняются в корзины (`buckets`) с шагом, зависящим от длины окна: 10 мин → 30 мин → 2 ч → 6 ч → сутки → неделя.
- Линия разрывается там, где данных не было (виджет был выключен): порог — максимум из «3 шагов» и «2,5 типичного интервала»
  (медиана расстояний между записями).
- Подписи оси выбираются по длине окна (часы / дни недели / числа / месяцы) и прореживаются, чтобы не налезать друг на друга
  и на метку «сейчас».
- Ползунок: `onContinuousHover` даёт долю ширины → ближайшая точка → подсказка с временем и значением.

## Календарь
Собственный календарь на SwiftUI (стандартный `DatePicker` в macOS мал и неудобен). Режимы «Один день» и «Период»
(два нажатия), точки под числами — за этот день есть данные, будущие дни и дни до начала истории неактивны,
быстрые периоды: «Вчера», «Прошлая неделя», «Прошлый месяц».

## Приватность
Файл лежит только на вашем Mac и никуда не отправляется. Чтобы начать с нуля — удалите его (при закрытом приложении).
