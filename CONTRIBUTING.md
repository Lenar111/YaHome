# Как помочь проекту

Спасибо за интерес! Проект небольшой, правила простые.

## Что особенно полезно
- **Новые типы устройств.** Если ваше устройство показывается не тем значком или в «Прочем», откройте issue
  и приложите *тип* устройства (`devices.types.…`) и название — без токенов и адресов. Правки делаются в
  `Dev.cat`, `Dev.symbol` и `allCats` (см. [docs/DEVICES.md](docs/DEVICES.md)).
- **Проверка на разных версиях macOS** (13, 14, 15, 26) и на разных экранах.
- **Локализация** (сейчас интерфейс русский).

## Как внести изменение
1. Форк → ветка `feature/…`.
2. `tools/build.sh build/YaHome --typecheck` — код должен компилироваться (то же самое делает CI).
3. Pull request с описанием *что* и *зачем*, по возможности со скриншотом.

## Стиль
- Один файл `Sources/YaHome.swift` разбит на блоки `// MARK: -`; новые вещи кладите в подходящий блок.
- Не используйте `@State` и макросы Swift (`@Observable` и т. п.) — состояние хранится в `ObservableObject`
  с `@Published`, привязки создаются через `Binding(get:set:)`. Так код собирается обычным `swiftc` без Xcode.
- Никаких зависимостей. Только системные фреймворки.
- Никаких секретов в коммитах: токены, ID устройств, адреса.
