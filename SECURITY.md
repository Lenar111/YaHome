# Безопасность

## Что хранится и где
- **OAuth-токен Яндекса** — только в связке ключей macOS (служба `local.yahome.menubar`, доступ «только на этом устройстве, когда Mac разблокирован»). Ни в файлах, ни в логах.
- **История датчиков** — `~/Library/Application Support/YaHome/history.json` (температура, влажность, CO₂, давление,
  мощность). Остаётся на вашем Mac.
- **Настройки** (избранное, порядок, элементы строки меню) — `UserDefaults`.
- Приложение обращается только к `api.iot.yandex.net` и `oauth.yandex.ru`. Аналитики и сторонних серверов нет.

## Вход
Токен получается через `oauth.yandex.ru` (implicit flow) с одноразовым параметром `state`: приёмник принимает токен только с тем `state`, который приложение само создало при входе. Страницу-приёмник на `127.0.0.1:8765` поднимает само
приложение на время входа (не более 10 минут), она доступна только с локального интерфейса.

## Сообщить об уязвимости
Пожалуйста, не открывайте публичный issue: напишите автору через GitHub (раздел *Security → Report a vulnerability*).
Если токен мог попасть не в те руки — отзовите доступ приложения в настройках безопасности вашего аккаунта Яндекса и войдите заново.

## Известные ограничения
- Ручная вставка токена — запасной способ входа по явному действию пользователя, `state` там не проверяется.
- Вход использует implicit flow (`response_type=token`): токен приходит во фрагменте адреса и живёт ограниченное время. Переход на Authorization Code + PKCE возможен, если Яндекс разрешит его для публичных клиентов, — пока не реализован.
- Приложение собирается на вашем Mac из открытых исходников (`swiftc`), подписывается ad-hoc и не нотаризовано Apple. Установщик **не снимает** карантин macOS.
- История датчиков хранится открытым JSON-файлом в вашей папке `Application Support`.
